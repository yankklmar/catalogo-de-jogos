# Catálogo de Jogos

Trabalho acadêmico desenvolvido para a disciplina de Engenharia de Software, com o objetivo de aplicar conceitos de estruturação, organização e manipulação de dados em uma aplicação de console.

##  Descrição

O **Catálogo de Jogos** é uma aplicação executada via terminal/console que permite ao usuário consultar e listar jogos previamente cadastrados no sistema, por meio de um menu de opções interativo.

##  Funcionalidades

- Listagem dos jogos cadastrados no catálogo
- Navegação por meio de menu de opções no terminal
- Estrutura simples e organizada para consulta de dados
